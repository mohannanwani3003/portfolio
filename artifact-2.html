Artifact 02 · Machine Learning Fundamentals

Machine Learning vs. Deep Learning

A comparison of two approaches to AI, using house price prediction and image recognition to explore which method is a better fit for different tasks.

Introduction

This artifact compares traditional machine learning and deep learning through two real-world examples. The goal was to understand that the best approach depends on the problem and the type of data being used.

Description

The assignment looks at house price prediction using linear regression as an example of traditional machine learning, and image recognition using a convolutional neural network (CNN) as an example of deep learning.

Traditional machine learningHouse price prediction using structured information such as location, square footage, number of bedrooms, and property age
Deep learningImage recognition to identify defects in manufactured products using X-ray images

Objective

The objective was to select two applications, explain why each learning approach is suitable, and consider why the alternative approach may be less practical for that task. The comparison highlights the importance of matching the model to the problem rather than choosing the most complex technology by default.

Process

I selected examples from the course lesson and researched real-world applications to support them. I then compared the type of data each task uses, the way useful patterns or features are identified, and the practical considerations involved, such as complexity and computing resources. I organized the comparison into an assignment document with an explanation and supporting references.

Tools and Technologies Used

Concepts discussed: Linear regression, structured data, deep learning, and convolutional neural networks (CNNs).

Deliverable: Word document prepared for the Machine Learning vs. Deep Learning coursework assignment.

Value Proposition

Unique Value

This work demonstrates my ability to compare technical approaches and explain their strengths and limitations using practical examples rather than assuming that a more advanced model is always the better choice.

Relevance

Understanding when to use traditional machine learning or deep learning is useful when evaluating AI solutions. It encourages me to consider the data, complexity, resources, and needs of the problem before selecting an approach.
